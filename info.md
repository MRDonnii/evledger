## EV Ledger

Track every trip and every charge — home or public — as one unified cost
ledger, powered entirely by entities from integrations you already have
installed (Tesla, Zaptec, Monta today). No vendor API calls, no extra
dependencies.

- Automatic trip detection (distance, route endpoints, battery used)
- Home charging cost from Zaptec (power/energy) + Monta (price)
- Public/away charging logged with one service call
- Ledger sensors ready to drop into a custom dashboard

See the [README](https://github.com/MRDonnii/evledger#readme) for setup and
the full sensor/service reference.
